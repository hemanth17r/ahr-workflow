# Brainstorm & Q&A Mode

## Rules
1. **Direct Chat Answers Only**: Answer the user's questions, explore ideas, compare architectural options, or explain concepts directly in chat responses.
2. **No Codebase Edits**: Do NOT create, modify, or delete any source files or project assets.
3. **No Implementation Plans**: Do NOT generate `implementation_plan.md` artifacts or formal plan workflows.
4. **High-Signal Output**: Adhere strictly to the BLUF protocol (1-sentence verdict up front, 2–4 decisive bullets, zero unprompted essays).
