# Plan-Only Mode

## Rules
1. **No Code Edits**: Do NOT create, modify, or delete any project files.
2. **Allowed Actions**: Answer questions, inspect codebase files, search documentation, and write implementation plans.
3. **Approval Required**: Present proposed changes and wait for explicit user approval before making any code modifications.
